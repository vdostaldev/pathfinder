How the algorithms work

  • BFS (breadth-first search) explores in rings around the start using a queue. It finds the path with the fewest steps but ignores weights.
  • DFS (depth-first search) goes as deep as it can down one direction using a stack before backtracking. It does not guarantee the shortest path.
  • Dijkstra always expands the cell with the lowest total cost so far (priority queue). It handles weights and always finds the cheapest path.
  • A* is Dijkstra plus a heuristic (Manhattan distance to the end), so it searches toward the target. It still finds the cheapest path but visits fewer cells.
  • Greedy best-first only uses the heuristic and ignores the cost so far. It is fast but the path is often not the shortest.

Tip: after a search finishes, moving the start or end, or changing the algorithm, updates the result immediately so you can compare them on the same board.
